# Libraries

Libraries that come with TomLang. Use one with `use files`, then call `files.readFile("a.txt")`.

Hovering over a library function in VS Code shows its description from these pages.

| Library | For | Status |
|---|---|---|
| [maths](maths.md) | numbers, rounding, primes, roots, trig, game helpers | done |
| [sort](sort.md) | sorting, reversing and searching lists | done |
| [text](text.md) | searching, splitting, trimming, padding and changing text | done |
| [files](files.md) | reading, writing, checking and organising files and folders | done |
| [time](time.md) | clocks, timing, sleeping, dates and formatting | done |
| [os](os.md) | environment variables, arguments, running programs, system info, clipboard | done |
| [json](json.md) | reading, writing and picking through JSON | done |
